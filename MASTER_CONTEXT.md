# MASTER CONTEXT — TraceMuse

Проект: локальный веб-сервис TraceMuse для предварительного аудита происхождения цифровых ресурсов, лицензий и российского правового контекста.

## Цель
Получить демонстрируемый локальный продукт для Windows 11 и достоверную курсовую работу МАИ. Не выдавать прототип за готовую юридическую систему.

## Принципы
1. Local-first: извлечение, хеширование, SQLite и отчёты работают локально.
2. Внешние API опциональны; перед передачей файлов требуется согласие.
3. Не выдумывать источники, лицензии, статусы, интервью, тесты и MCP-вызовы.
4. Разделять подтверждённые факты, гипотезы и неизвестные данные.
5. Правовые категории проверять отдельно и только по официальным актуальным источникам.
6. Сохранять совместимость предыдущих этапов; не пересоздавать проект с нуля.

## Стек
Frontend: React, TypeScript, Vite, Tailwind CSS (подключение/доработка на этапе UI).
Backend: Python, FastAPI, SQLite.
Обработка планируется: python-pptx, python-docx, PyMuPDF, Pillow, BeautifulSoup, OCR и безопасная обработка ZIP/SVG.
