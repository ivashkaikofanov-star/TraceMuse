# TraceMuse Audit Skill

## Назначение
Инструкция для последовательного предварительного аудита цифрового материала. Skill не является юридическим заключением и не гарантирует обнаружение всех источников.

## Обязательные принципы
1. Не выдумывай автора, правообладателя, источник, лицензию, дату или правовой статус.
2. Разделяй подтверждённые факты, вероятные совпадения и неизвестные сведения.
3. Не считай визуальное сходство доказательством копирования.
4. Не считай отсутствие лицензии доказательством нарушения.
5. Не считай указание автора достаточным разрешением, если лицензия требует отдельного разрешения.
6. Для каждого внешнего утверждения сохраняй URL и дату получения.
7. Не отправляй файл во внешнюю систему без явного согласия пользователя.
8. Правовые категории РФ проверяй раздельно по официальным актуальным реестрам.
9. Фиксируй контекст: страница, слайд, раздел, URL или координаты элемента.
10. Если проверка не удалась, явно укажи причину и статус «не проверено».

## Процедура аудита
### A. Инвентаризация
- Определи формат, размер, имя и SHA-256.
- Извлеки текст, изображения, ссылки, метаданные и доступные сведения о шрифтах.
- Для каждого ресурса создай уникальный ID.
- Сохрани позицию и контекст в исходном материале.

### B. Поиск источника
- Начни с точных URL, встроенных метаданных, названий и текстовых фрагментов.
- Для изображений используй точный хеш, затем perceptual hash/визуальный поиск как сигнал, а не доказательство.
- Для текстов используй точные фрагменты и поиск цитат.
- Сохрани запрос, найденный URL, дату и релевантный фрагмент.
- Оцени надёжность источника отдельно от сходства.

### C. Лицензия
- Найди первичную страницу материала и лицензионный текст.
- Зафиксируй коммерческое использование, производные работы, атрибуцию, share-alike, ограничения и исключения.
- Если условия не найдены или неоднозначны — статус «не установлено», не делай предположений.

### D. Российский правовой контекст
- Разделяй категории: иностранные агенты, нежелательные организации, экстремистские материалы/организации, террористические организации, запрещённые организации, ограниченные сервисы и иные специальные требования.
- Проверяй точное совпадение названия и контекст, избегай совпадения только по похожей строке.
- Для каждого совпадения фиксируй официальный источник, дату проверки, применимую категорию и степень уверенности.
- Не приравнивай упоминание к нарушению или блокировку сайта к запрету любого упоминания.
- Маркировку предлагай только как вопрос для проверки применимости; не вноси её в исходник без согласия.

### E. Оценка риска
Используй отдельные оценки по категориям: низкий, средний, высокий, неопределённо, требуется ручная проверка. Объясни факторы оценки и уровень уверенности. Не называй риск юридически установленным нарушением.

### F. Рекомендации
Предлагай только обоснованные действия: уточнить лицензию, получить разрешение, корректно атрибутировать, заменить ресурс, удалить ресурс, проверить маркировку, обратиться к юристу. Не предлагай атрибуцию вместо разрешения, если оно требуется.

## Формат результата для ресурса
- ID и тип ресурса
- контекст/позиция
- SHA-256 или иной идентификатор
- найденный источник и дата
- автор/правообладатель (если подтверждён)
- лицензия и условия (если подтверждены)
- отдельные правовые совпадения
- оценка риска и обоснование
- уверенность
- рекомендации
- ограничения проверки
