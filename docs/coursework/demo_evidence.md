# Прогон по TraceMuse Audit Skill

27 ноября 2026 года в 19:30 мск провели локальную проверку открытого учебного HTML по правилам проектной Skill. Сетевой поиск и DeepSeek были выключены. FastAPI работал под Uvicorn с отдельной временной SQLite. [Демоматериал](demo-material.html) · [Skill](../../skills/tracemuse-audit/SKILL.md)

| Шаг | Фактический результат |
| --- | --- |
| Инвентаризация | HTML, 1 395 байт. SHA-256 `e23c9375ccb45b4ff3f637a54fd34c5f410ba502c1ec384f462afbf8c398f054` совпал с локальным вычислением. Извлечены русскоязычный текст, заголовок, описание, язык и кодировка. |
| Источники | В документе есть одна справочная ссылка. Отчёт показал её как ссылку из материала, с непроверенной связью с первоисточником. |
| Лицензия | Условия использования документа остались неподтверждёнными. Ссылка ведёт на обзор лицензий, который сам по себе не устанавливает условия использования конкретного документа. |
| Правовые категории | Отчёт выдал ссылки для ручной сверки. Локальный снимок реестров отсутствовал, поэтому прогон не подтверждал правовой статус и применимость маркировки. |
| Оценка | «Недостаточно данных» об условиях использования всего материала. Отчёт предложил подтвердить первоисточник и права на материалы перед публикацией. |
| Экспорт и хранение | JSON совпал с деталями проверки в API. Из четырёхстраничного PDF прочитан кириллический заголовок исходного материала. История и данные проверки сохранились после остановки и нового запуска Uvicorn с той же SQLite. |

Этот прогон демонстрирует локальный сценарий и объяснение границ аудита. Для проверки Wikimedia Commons и для DeepSeek нужны отдельные прогоны с соответствующими настройками. [Справочная ссылка из материала](https://creativecommons.org/share-your-work/cclicenses/)
