# Источники

На этапе 1 использована концепция проекта, предоставленная пользователем. Внешние технические и правовые источники ещё не исследовались и не должны считаться использованными.

При добавлении источника фиксировать:
- название;
- организацию/автора;
- URL;
- дату публикации/обновления (если доступна);
- дату обращения;
- конкретное утверждение, для которого использован источник.
