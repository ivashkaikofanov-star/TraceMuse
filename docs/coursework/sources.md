# Источники

Дата обращения 27 ноября 2026 года.

- FastAPI. Загрузка нескольких файлов и потоковое чтение `UploadFile`. Документация, полученная через Context7 MCP, использована для проверки реализации multipart. [FastAPI](https://fastapi.tiangolo.com/tutorial/request-files/) · [UploadFile](https://fastapi.tiangolo.com/reference/uploadfile/)
- Wikimedia Commons. Публичный оригинал, использованный для проверки поиска по SHA-1 и визуального сравнения. [Cat November 2010-1a.jpg](https://commons.wikimedia.org/wiki/File:Cat_November_2010-1a.jpg)
- Creative Commons. Ссылки, по которым модуль распознаёт условия лицензий Creative Commons. [Виды лицензий](https://creativecommons.org/share-your-work/cclicenses/) · [CC0](https://creativecommons.org/publicdomain/zero/1.0/)
- DeepSeek. Настройка модели и доступность адреса API. [Справочник API](https://api-docs.deepseek.com/) · [Модели](https://api-docs.deepseek.com/quick_start/pricing)
- Организации и правовые категории. Официальные ссылки доступны в настройках TraceMuse. В автоматизированных тестах использованы искусственные записи для проверки алгоритма сопоставления.
