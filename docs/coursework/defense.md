# Подготовка к защите

## Основной тезис
TraceMuse — локальный инструмент предварительного аудита цифровых материалов, который помогает структурировать найденные ресурсы, источники, лицензии и зоны правовой неопределённости.

## Что продемонстрировать после реализации
1. Запуск локального приложения.
2. Загрузка презентации/документа.
3. Извлечение ресурсов с указанием слайда/страницы.
4. Просмотр источников и доказательств.
5. Раздельный блок правового контекста РФ.
6. Формирование и экспорт отчёта.
7. Работа истории после перезапуска.

## Ограничения, которые важно озвучить
Автоматический аудит не заменяет юридическое заключение; совпадение не доказывает копирование; отсутствие найденной лицензии не означает нарушение; полнота зависит от доступности источников.

## Данные для титульного листа
ФИО, группа, кафедра, дисциплина, преподаватель, дата защиты — запросить у пользователя позднее.
