# Защита курсовой TraceMuse

TraceMuse помогает авторам цифровых материалов проверять источники и условия использования до публикации. Сервис сохраняет ход проверки и показывает, какие сведения можно подтвердить, где данных недостаточно и какие вопросы требуют ручной проверки.

## Готовые материалы

- [Презентация](presentation.html) открывается в браузере. Клавиши ← и → переключают слайды. Через `Ctrl+P` можно сохранить презентацию в PDF.
- [Демонстрационный HTML](demo-material.html) содержит открытый учебный текст и публичную справочную ссылку. На нём удобно показывать извлечение и отчёт.
- [Протокол демонстрационной проверки по Skill](demo_evidence.md) фиксирует результаты прогона и восстановления истории после перезапуска.
- [Протокол реального вызова MCP](mcp_usage.md) содержит команду для живой демонстрации.
- [Проектная Skill](../../skills/tracemuse-audit/SKILL.md) задаёт правила работы с источниками, лицензиями, реестрами и неизвестными сведениями.
- [Актуальный статус проекта и проверок](../../PROJECT_STATUS.md).

## Сценарий демонстрации

1. Открыть локальный TraceMuse. Загрузить `docs/coursework/demo-material.html` через раздел «Новая проверка». Для первого прогона оставить внешний поиск и DeepSeek выключенными.
2. В результате открыть извлечённый текст, ссылки, формат и SHA-256. Сопоставить ссылки с содержимым демофайла и показать, почему одной встроенной ссылки недостаточно для подтверждения условий использования материала.
3. Открыть блок правовой проверки и объяснить, какие сведения можно подтвердить в официальном источнике и в каком случае нужна ручная проверка. Показать объяснение общей оценки.
4. Скачать PDF и JSON. Перезапустить сервер и открыть тот же результат из истории. Показать повторный запуск с собственными параметрами.
5. При наличии сети повторить вызов Context7 MCP. Если для защиты подключён DeepSeek, проверить соединение в настройках, затем включить ИИ при повторной проверке открытого демоматериала.

Для демонстрации подтверждённого совпадения подготовить заранее публичный оригинал из Wikimedia Commons с доступными сведениями о лицензии и убедиться, что фактический прогон вернул карточку источника. Использовать отчёт прогона как свидетельство результата вместе с датой запроса и ссылкой на карточку каталога.

## Данные для титульного слайда и отчёта

Заполнить по данным студента и кафедры. Нужны ФИО, группа, кафедра, дисциплина, преподаватель и дата защиты. Результаты интервью, опросов и пользовательских тестов добавлять после их проведения. [План исследования](user_research.md)
