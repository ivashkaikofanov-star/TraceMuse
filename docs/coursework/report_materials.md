# Материалы для итогового отчёта МАИ

Предварительная структура (будет уточнена по официальному шаблону кафедры):
1. Титульный лист МАИ.
2. Краткая аннотация.
3. Содержание.
4. Введение.
5. Проблема и предлагаемое решение.
6. Пользователи и их задачи.
7. Пользовательский путь.
8. Требования MVP.
9. Реализация и запуск.
10. Архитектура.
11. Основной сценарий.
12. Использование ИИ, Skill и MCP.
13. Агентные роли и передача результатов.
14. Проверка приложения.
15. Личный вклад.
16. Заключение.
17. Список источников.
18. Приложения со скриншотами.

## Неизвестные сведения
ФИО, группа, кафедра, дисциплина, преподаватель, дата защиты и точный шаблон отчёта пока не предоставлены. Не заполнять предположениями.

## Учёт объёма
При подготовке DOCX вести перечень страниц, рисунков, таблиц, источников и приложений по фактически сформированному документу. Нумерацию страниц окончательно сверять после открытия документа в Word/LibreOffice.
