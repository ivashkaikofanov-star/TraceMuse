# Использование ИИ

Codex применялся для реализации модулей, проектирования контракта API и проверки приложения. Артефакты и фактические результаты нескольких ролей описаны в [журнале передач](agent_handoffs.md). Во время разработки проектная Skill использована для [контрольного аудита](demo_evidence.md).

В приложении DeepSeek включается отдельным согласием на конкретную проверку. Сервер отправляет ограниченные выдержки из извлечённого текста и выбранные записи найденных доказательств. Ответ привязывается к переданным идентификаторам и дословным цитатам. TraceMuse формирует пользовательские наблюдения из фиксированных формулировок и проверенных цитат. Условия лицензий и правовые статусы по-прежнему берутся из исходных сведений отчёта.

В тестах ответ API заменялся контролируемыми ответами для проверки структуры, истечения лимитов и отклонения выдуманных цитат. К реальному `/models` выполнен запрос без учётных данных, сервис вернул HTTP 401. Для подтверждения успешного вызова используются локальный ключ и кнопка проверки соединения.
