# Использование ИИ

ИИ используется как помощник при проектировании архитектуры, подготовке кода, документации и тестовых сценариев.

Для каждого существенного использования фиксировать:
- дату;
- модель/инструмент (если достоверно известны);
- задачу и текст запроса;
- полученный результат;
- что принято/отклонено;
- способ проверки.

Не приписывать ИИ автономные действия, которые фактически не выполнялись. На текущем этапе подготовлены архитектурные решения, стартовые файлы и документация. Фактическая проверка приложения на Windows пользователем ещё не проводилась.
