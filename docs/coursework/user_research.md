# Пользовательское исследование

Статус: не проводилось. Участники, ответы и количественные результаты не вымышляются.

## План интервью
1. Какие типы цифровых материалов вы создаёте?
2. Как сейчас проверяете происхождение изображений, шрифтов и текстов?
3. Какие источники используете для проверки лицензий?
4. Сколько времени занимает проверка одного проекта?
5. Какие ошибки или риски встречались?
6. Какие сведения должны быть в итоговом отчёте?
7. Какие данные нельзя передавать внешним сервисам?
8. Какие форматы файлов наиболее важны?

## План опроса
После пилотных интервью подготовить короткий опрос с вопросами о частоте использования ресурсов, способах проверки, приоритетных форматах и ожидаемой ценности сервиса.

## Фиксация результатов
Для каждой беседы указать дату, обезличенный код участника, метод, краткие наблюдения и продуктовые решения. До проведения оставить раздел незаполненным.
