# Тестирование TraceMuse 0.2.0

Проверки проведены 27 ноября 2026 года в Linux. Backend проверен с Python 3.13.5. Frontend собран с Node.js 24.22.3 и проверен в Chromium.

| Проверка | Фактический результат |
| --- | --- |
| `python -m pytest -q` из `backend` | 28 тестов и 10 подтестов прошли. Starlette выдал предупреждение о будущем изменении клиента тестов |
| `npm ci` и `npm run build` из `frontend` | Зависимости установлены по lock-файлу. TypeScript и production-сборка Vite прошли |
| Извлечение | Пройдено на девяти форматах. Полные документы Word и PowerPoint с кириллицей и встроенным изображением дополнительно проверены локально |
| API, SQLite, экспорт | Пройдено создание пакета, сверка SHA-256, миграция старой SQLite, PDF с кириллицей, JSON, повтор, удаление и восстановление файлов после прерванной операции |
| Перезапуск | Uvicorn остановлен и запущен снова. История и сведения учебной проверки доступны из той же SQLite. [Демонстрационный прогон](demo_evidence.md) |
| Chromium, 1440 и 390 пикселей | Проверены рабочий кабинет, изображения и шрифты интерфейса, мобильная навигация, согласия, обработка успешных и отклонённых файлов, скачивание отчётов, повтор и удаление, настройки без ключа. [Скриншоты](screenshots/) |
| Wikimedia Commons | Живой текстовый поиск вернул записи каталога и лицензии. Оригинал найден по SHA-1. Уменьшенный перекодированный файл сопоставлен по трём публичным миниатюрам |
| Правовые источники | Схема локального снимка и точное сопоставление проверены на тестовых данных. Порталы Минюста вернули HTTP 403, Росфинмониторинг HTTP 503, Роскомнадзор не ответил за отведённое время |
| DeepSeek | Проверены запросы с управляемыми тестовыми ответами, отсутствие запроса без согласия, обработка ошибок, хранение ключа и проверка привязки цитат. Реальный `/models` вернул HTTP 401 при запросе без ключа |
| Презентация | Chromium проверил навигацию кнопками и клавишами, ширину 380 пикселей и печать восьми слайдов в PDF. [Презентация](presentation.html) |
| Context7 MCP | В реальном сеансе получены документация FastAPI и подтверждение работы `UploadFile`. [Протокол](mcp_usage.md) |

Авторизованный сетевой анализ DeepSeek с ключом и работа на Windows 11 остаются открытыми проверками. Интервью и пользовательское тестирование ещё не проводились.
