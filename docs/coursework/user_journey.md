# Пользовательский путь

1. Пользователь открывает TraceMuse в браузере и выбирает «Новая проверка».
2. Выбирает или перетаскивает файлы. При необходимости уточняет предполагаемое использование и даёт отдельное согласие на поиск в Commons или анализ DeepSeek.
3. TraceMuse извлекает доступные сведения, рассчитывает хеши и сохраняет результаты. Для непринятых файлов показывает причину.
4. Пользователь открывает детали, сверяет источники, условия, правовые сведения, ограничения и рекомендации.
5. Скачивает PDF или JSON. Через историю может вернуться к результату, повторить проверку или удалить её вместе с локальным оригиналом.

Учебный пример и фактический результат описаны в [демонстрационном прогоне](demo_evidence.md).
