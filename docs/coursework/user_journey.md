# Пользовательский путь

1. Пользователь открывает локальный TraceMuse.
2. Создаёт проверку и указывает название проекта.
3. Загружает файл или добавляет URL.
4. Подтверждает локальную обработку и отдельно — возможную передачу данных внешнему сервису.
5. Сервис извлекает ресурсы и сохраняет контекст их расположения.
6. Пользователь просматривает каждый найденный ресурс и доступные доказательства.
7. Пользователь изучает раздельные категории рисков и неопределённости.
8. Пользователь применяет рекомендации вручную и формирует отчёт.

Текущий интерфейсный сценарий является проектируемым; функциональность загрузки и анализа будет реализована последующими этапами.
