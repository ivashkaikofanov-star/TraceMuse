# Сторонний MCP в разработке TraceMuse

27 ноября 2026 года в 19:27 мск клиент TraceMuse выполнил реальный вызов публичного сервера Context7 4.9.1. Через Streamable HTTP сервер согласовал протокол MCP 2025-03-26 и вернул список инструментов. [Сервер Context7](https://mcp.context7.com/mcp) · [Выгрузка фактического ответа](mcp_evidence.json)

| Вызов | Запрос и результат |
| --- | --- |
| `tools/call` → `resolve-library-id` | По названию FastAPI и запросу о загрузке файлов получил каталог `/websites/fastapi_tiangolo`. |
| `tools/call` → `query-docs` | По каталогу FastAPI и запросу о пакетной загрузке получил документацию `list[UploadFile]` и `UploadFile.read(size)` со ссылками на первоисточник. |

Результат передан разработчику API для пакетной загрузки. Описанные в FastAPI `UploadFile` и чтение ограниченными порциями подходят для передачи списка файлов и применения предела размера при сохранении каждого файла. Работоспособность загрузки приложения подтверждается его собственными тестами. [Пакетная загрузка в документации FastAPI](https://fastapi.tiangolo.com/tutorial/request-files/) · [API `UploadFile`](https://fastapi.tiangolo.com/reference/uploadfile/)

Из корня проекта в PowerShell можно повторить обе операции одним вызовом. Скрипт проходит инициализацию, проверяет наличие инструментов и выводит компактный JSON с датой, аргументами и выдержками. Нужен доступ в Интернет.

```powershell
py -3.13 .\tools\check_mcp.py
```

Сеть получает два заданных в скрипте запроса об открытой документации FastAPI. Клиент MCP запускается отдельно и используется для разработки и демонстрации курсовой. Поиск пользовательских материалов выполняет соответствующий модуль TraceMuse по отдельному согласию.
