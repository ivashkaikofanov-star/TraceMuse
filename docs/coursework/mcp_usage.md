# Использование стороннего MCP

Статус: реальный вызов MCP пока не выполнен.

Кандидаты для последующего подключения:
- Microsoft Learn MCP — https://learn.microsoft.com/api/mcp
- DeepWiki MCP — https://mcp.deepwiki.com/mcp

После фактического вызова зафиксировать сервер, URL, точное имя инструмента, параметры без секретов, ответ, влияние на архитектуру и способ проверки. Не заполнять фиктивными данными.
