# Требования MVP

| ID | Функция | Критерий приёмки / способ проверки | Статус |
|---|---|---|---|
| F-01 | Локальный запуск | Frontend и API запускаются на Windows 11 | Не проверено |
| F-02 | Загрузка документов | Валидные форматы принимаются, неподдерживаемые отклоняются безопасно | Запланировано |
| F-03 | Извлечение ресурсов | Текст, изображения, ссылки и позиции извлекаются с контекстом | Запланировано |
| F-04 | Хеширование | Для каждого файла вычисляется SHA-256 | Запланировано |
| F-05 | Поиск источников | Источник сопровождается URL и датой получения | Запланировано |
| F-06 | Проверка лицензии | Тип и условия лицензии не выводятся без подтверждения | Запланировано |
| F-07 | Правовой контекст РФ | Категории статусов разделены, указаны официальные источники и дата проверки | Запланировано |
| F-08 | История | Проверки сохраняются в SQLite после перезапуска | Частично: схема БД |
| F-09 | Экспорт | Доступны PDF и JSON | Запланировано |
| F-10 | Приватность | Внешняя передача отключена без явного согласия | Архитектурное требование |
