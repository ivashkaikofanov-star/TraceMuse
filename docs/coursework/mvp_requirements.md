# Требования MVP

| ID | Функция | Критерий приёмки | Статус |
| --- | --- | --- | --- |
| F-01 | Локальный запуск | Открывается собранный интерфейс и доступен API | Пройдено на Linux. Windows 11 ожидает проверки |
| F-02 | Загрузка | Поддерживаемые форматы принимаются в одном запросе, ошибки указаны по файлам | Проверено |
| F-03 | Извлечение | Сохраняются текст, ссылки, изображения и метаданные по формату | Проверено для девяти форматов |
| F-04 | Хеширование | SHA-256 совпадает с независимым вычислением | Проверено |
| F-05 | Поиск | Commons возвращает сигнал с URL, временем и способом сопоставления | Проверено на публичном материале |
| F-06 | Лицензия | Происхождение заявления и доступные условия показаны | Проверено на данных каталога и фикстурах лицензий |
| F-07 | Правовой контекст РФ | Категории разделены, есть ссылки и точная сверка снимка при наличии | Проверено на фикстурах. Актуальные сведения сверяются вручную |
| F-08 | История | Данные видны после перезапуска, доступны повтор и удаление | Проверено |
| F-09 | Экспорт | PDF с кириллицей и JSON доступны для скачивания | Проверено |
| F-10 | Приватность | Обе внешние опции выключены по умолчанию | Проверено |
| F-11 | DeepSeek | Ключ хранится локально, результат основан на переданных доказательствах | Проверено с тестовым транспортом. Авторизованный сетевой запрос ожидает ключа |
