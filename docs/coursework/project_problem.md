# Проблема и обоснование проекта

TraceMuse предназначен для предварительного аудита происхождения цифровых ресурсов в документах, презентациях и веб-проектах.

## Проблема
При подготовке цифровых материалов пользователю сложно вручную установить первоисточник, автора, лицензионные условия и применимые ограничения. Отсутствие найденной лицензии не доказывает нарушение, но создаёт неопределённость, которую важно выявить до публикации.

## Целевая аудитория
Дизайнеры, разработчики, маркетологи, студенты и авторы цифрового контента.

## Предлагаемое решение
Локальное приложение, которое извлекает отдельные ресурсы, фиксирует контекст, помогает искать подтверждаемые сведения и формирует отчёт с указанием неопределённостей.

## Статус исследования
Пользовательское исследование пока не проводилось. Гипотезы о проблемах аудитории подлежат проверке интервью и опросом.
