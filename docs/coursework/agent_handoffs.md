# Передача результатов между ролями

27 ноября 2026 года ведущая роль согласовала контракт API и связала работу пяти отдельных агентов Codex в одном репозитории. Каждая роль передала исходники, наблюдения и границы проверок.

| Роль | Передано ведущей роли | Проверка |
| --- | --- | --- |
| Извлечение | Обработчики форматов и тесты входных файлов | Набор из девяти форматов, извлечение кириллицы и встроенного изображения из полных пакетов Office, лимиты парсеров |
| Источники | Адаптер Wikimedia Commons, условия лицензий и сверка снимков реестров | Реальные поисковые запросы, точное совпадение публичного файла и сравнение публичных миниатюр. Фикстуры правовых данных |
| ИИ и отчёт | Клиент DeepSeek, хранилище ключа, PDF и шрифты | Тесты согласия, ошибок и проверяемых цитат, PDF с кириллицей и ссылками |
| Интерфейс | React-страницы и настройки, адаптивное чёрно-оранжевое оформление | Сборка Vite и проверка сценариев в Chromium |
| Документация и MCP | Клиент Context7, подтверждения вызова, презентация, демонстрационный HTML | Реальный вызов MCP, Chromium, аудит по Skill с перезапуском Uvicorn |

Ведущая роль реализовала API, хранилище и оценку риска, провела интеграционные проверки и собрала архив. В журнале описаны действия при разработке. Участие автора в курсовой работе заполняется по фактическим данным автора.
