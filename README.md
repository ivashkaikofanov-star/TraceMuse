# TraceMuse

Локальный сервис предварительного аудита цифровых материалов: извлечение ресурсов, фиксация источников, проверка лицензий и формирование отчётов.

## Статус
Начальная основа проекта (этап 1). Это не готовая система юридической проверки: сетевой поиск источников, OCR, AI-анализ и правовые реестры будут подключаться отдельными этапами.

## Требования
- Windows 11
- Python 3.11+
- Node.js 20+

## Запуск в режиме разработки
### Backend
```powershell
cd backend
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
uvicorn app.main:app --reload
```
API: http://127.0.0.1:8000, документация: http://127.0.0.1:8000/docs

### Frontend
В отдельном окне PowerShell:
```powershell
cd frontend
npm install
npm run dev
```
Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Локальные данные
SQLite и загруженные файлы хранятся в `backend/data/`. Папка исключена из Git. Не помещайте секреты в исходный код. Для локальных секретов используйте `backend/.env` (образец — `.env.example`).

## Принципы достоверности
- Неизвестная лицензия не означает нарушение.
- Визуальное сходство не доказывает копирование.
- Правовые совпадения требуют проверки контекста и актуальности официального источника.
- Сторонние API не получают файлы без отдельного согласия пользователя.
