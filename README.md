# TraceMuse

TraceMuse — локальное веб-приложение для предварительной проверки цифровых материалов перед публикацией. Оно извлекает содержимое и метаданные, сохраняет проверку в SQLite, показывает найденные сведения и формирует PDF и JSON. Поиск в Wikimedia Commons и анализ DeepSeek включаются пользователем для каждой проверки.

## Запуск на Windows 11

Нужны Python 3.13 и Node.js, поддерживаемый установленной версией Vite. Запустите в терминале PowerShell в VS Code, из папки проекта:

```powershell
py -3.13 -m venv backend\.venv
.\backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
.\backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Откройте <http://127.0.0.1:8000>. Для следующих запусков достаточно последней команды. Повторяйте сборку при изменении фронтенда. `Ctrl+C` останавливает сервер. Документация API доступна по адресу <http://127.0.0.1:8000/docs>.

Для разработки запустите backend с `--reload`, а во втором терминале выполните `npm.cmd --prefix frontend run dev` и откройте <http://127.0.0.1:5173>. Vite перенаправляет `/api` на `127.0.0.1:8000`.

## Проверка материала

1. Откройте «Новая проверка» и выберите до 10 файлов общим размером до 100 МиБ. Поддерживаются PDF, DOCX, PPTX, HTML, PNG, JPEG, WEBP, SVG и ZIP.
2. Для поиска лицензий и замен включите «Поиск источников онлайн». Подключённая модель МАИ или DeepSeek будет задействована в этом же режиме. Пользователь получает условия коммерческого использования исходника и отдельные сведения об изменённых версиях.
3. Откройте отчёт и скопируйте готовую подпись либо выберите предложенную замену. PDF содержит изображения и выводы. JSON также сохраняет подробности проверки.
4. История сохраняется между запусками. Повтор создаёт новую запись. Удаление убирает запись и её локальный исходный файл.

Загруженные файлы, SQLite и локальный ключ хранятся в `backend/data/`. По умолчанию приложение слушает только локальный адрес. Настройки окружения можно задать в `backend/.env` по образцу `backend/.env.example`.

### Готовые исправления для изображений

Раздел «Права на изображения» показывает исходную фотографию, её место в PPTX или PDF, найденную лицензию и вывод о коммерческом использовании. При CC BY и CC BY-SA отчёт показывает готовую подпись и дополнительные условия, если они применимы. При CC BY-NC он объясняет, почему атрибуции недостаточно. Для точного CC0 показывается вывод о возможности оставить исходник без подписи. При отсутствии доказательств отчёт указывает, что разрешение не установлено.

Если для исходника нужна подпись, TraceMuse дополнительно ищет замену без подписи. При неподтверждённых или неподходящих условиях он может показать и альтернативу с подписью, если без подписи ничего не нашлось или вариант с атрибуцией визуально ближе. Копии оригинала исключаются из замен. Превью исходников и найденных замен сохраняются локально в отчёте и встраиваются в PDF. Для форматов, которые не удалось отобразить, указывается отсутствие превью.

ИИ формулирует предметные запросы по контексту и помогает выбирать между визуально сопоставимыми заменами. При онлайн-проверке TraceMuse ищет каждое уникальное извлечённое растровое изображение с доступным превью. Для просмотра превью и повторной выгрузки старой проверки потребуется запустить её заново.

Чтобы расширить подбор замен, создайте API-ключ Pixabay и задайте `PIXABAY_API_KEY` в локальном `backend/.env`. Если у Commons нет подходящей замены без подписи, сервис проверит Pixabay и укажет условия лицензии. Лицензия фотобанка для оригинала показывается, если официальная запись Pixabay привязана к исходнику совпадением пикселей. [Условия Pixabay](https://pixabay.com/service/license-summary/) · [Документация API](https://pixabay.com/api/docs/)

TraceMuse открывает публичные страницы и файлы по ссылкам из материала и сверяет их с изображениями. Если ссылки остались в другой версии PowerPoint, при включённом онлайн-поиске нажмите «Добавить PPTX со ссылками». TraceMuse извлечёт ссылки из неё и сверит их с картинками основного файла, включая через `img_url` в ссылках Яндекс Картинок. Для этой сверки API-ключ не нужен. Дополнительная презентация учитывается в общем лимите загрузки и не сохраняется для повторной проверки.

### Обратный поиск изображений

При включении «Поиска источников онлайн» автоматически включается «Обратный поиск изображений». Его можно отключить отдельно. TraceMuse передаёт уменьшенные JPEG-копии в Яндекс через PicImageSearch. При капче, пустой выдаче или ошибке он пробует Google Lens. Для этих двух движков в TraceMuse не нужны ключи или биллинг. У приложения нет месячной квоты на поиск. Внешние сайты могут ограничивать частоту запросов. [PicImageSearch](https://pic-image-search.kituin.fun/engines/yandex/) · [Google Lens Pro](https://pypi.org/project/google-lens-pro/)

Google Lens использует отдельное окружение из-за несовместимых зависимостей. Для установки резерва на Windows один раз выполните из корня репозитория:

```powershell
.\backend\.venv\Scripts\python.exe -m venv backend\.venv-lens
.\backend\.venv-lens\Scripts\python.exe -m pip install -r backend\requirements-lens.txt
.\backend\.venv-lens\Scripts\python.exe -m patchright install chromium
```

При желании подключите третьим движком бесплатную зону SERP API Bright Data. Укажите её прокси-логин и пароль в `BRIGHT_DATA_PROXY_USER` и `BRIGHT_DATA_PROXY_PASSWORD` в `backend/.env`. Если для зоны нужно добавить сертификат провайдера, укажите путь к нему в `BRIGHT_DATA_CA_FILE`. Перезапустите TraceMuse. Bright Data заявляет 5 000 запросов в месяц в бесплатной зоне без карты. [Тариф](https://brightdata.com/pricing/serp) · [Загрузка файла через Lens](https://docs.brightdata.com/products/serp-api/query-parameters/google#google-lens)

Отчёт показывает, какой движок вернул страницы и какие из них удалось сверить. Совпадение картинки служит поводом открыть страницу и проверить условия использования конкретного материала.

### Проверка лицензий и подбор замены

При проверке результатов обратного поиска TraceMuse отдаёт приоритет Wikimedia Commons, Freepik, Unsplash, Pexels и Pixabay. Лицензия проверяется по полям конкретного изображения в JSON-LD и Microdata, затем по встроенным сведениям IPTC/XMP и правилам площадки. Если сайт ограничил доступ к карточке (HTTP 403), отчёт указывает на необходимость ручной проверки. Для неподтверждённых оригиналов TraceMuse подбирает фото через выдачу Яндекса с ограничением по сайту и проверяет условия на карточке кандидата. Подтверждённые варианты показываются в отчёте с превью.

Для чтения встроенных сведений установите ExifTool. TraceMuse подхватит `C:/VS CODE/exiftool-13.64_64/exiftool.exe` из `backend/.env.defaults`, если файл есть на компьютере. Для другого места установки задайте `EXIFTOOL_PATH` в личном `backend/.env` или добавьте программу в PATH. После изменения настроек перезапустите сервер. [Загрузить ExifTool](https://exiftool.org/)

## DeepSeek

1. Создайте ключ в [кабинете DeepSeek](https://platform.deepseek.com/api_keys).
2. В TraceMuse откройте «Настройки», вставьте ключ и сохраните его. Нажмите «Проверить подключение».
3. Включите «Поиск источников онлайн» при запуске конкретной проверки. Сохранение ключа само по себе не включает передачу данных.

По умолчанию TraceMuse использует `deepseek-flash` (DeepSeek V4.1 Flash). Старые значения `deepseek-v4-flash` и `deepseek-v4-flash-vision-exp` в `DEEPSEEK_MODEL` автоматически приводятся к актуальному идентификатору. [Модели DeepSeek](https://api-docs.deepseek.com/quick_start/pricing)

На Windows клиентский ключ сохраняется через DPAPI текущей учётной записи. На системах POSIX локальный файл ключа доступен только владельцу. Ключ из `backend/.env` можно убрать, удалив соответствующее значение из файла и перезапустив backend.

## API МАИ

Для запуска с университетским шлюзом установите `$env:AI_PROVIDER = 'mai'` перед запуском backend. В «Настройках» появится «МАИ API». Сохраните ключ, выданный МАИ, и нажмите «Проверить подключение». Проверка запрашивает список моделей. Для первого запроса к модели запустите проверку тестового файла с опцией «Поиск источников онлайн».

По умолчанию используется `deepseek-v4.1-flash` через `https://api-ai.mai.ru/v1`. Ключи МАИ и публичного DeepSeek сохраняются отдельно. Для выбора другой модели задайте `MAI_MODEL` с точным ID из списка API.

HTTPS-сертификат проверяется по умолчанию. Для разового тестового запуска при ошибке `SEC_E_UNTRUSTED_ROOT` можно явно задать `$env:MAI_TLS_VERIFY = 'false'` перед запуском. Это отключает проверку подлинности только для шлюза МАИ. Ключ и данные при перехвате соединения могут быть раскрыты. Для обычного режима установите `$env:MAI_TLS_VERIFY = 'true'` и используйте доверенную цепочку сертификатов.

## Какие данные передаются

- Без внешних опций обработка выполняется локально. Встроенные ссылки не открываются автоматически.
- При поиске Wikimedia Commons получает ограниченные фрагменты текста, хеши и поисковые запросы из описаний и контекста. TraceMuse может скачать публичные изображения Commons для сравнения.
- При анализе выбранный провайдер получает ограниченные текстовые выдержки, контекст слайдов и выбранные сведения о найденных источниках, кандидатах на замену и реестрах. Оригинальные файлы в модель не передаются.
- Если настроен Pixabay, при онлайн-поиске он может получить короткий запрос по теме изображения. Ответы кэшируются локально на 24 часа.
- При обратном поиске Яндекс, резервный Google Lens и опциональный Bright Data получают уменьшенные копии изображений. Превью для отчётов хранятся локально, в том числе в офлайн-проверках.

Результаты показывают доступные сведения, происхождение кандидатов и ограничения проверки. Для сканированных PDF OCR не выполняется. Совпадения в Commons и локальном снимке реестра требуют проверки по источнику и контексту применения. Начальный режим проверок РФ показывает официальные ссылки для ручной сверки.

TraceMuse локально сверяет растровую графику со встроенными образцами Pepsi, adidas и Coca-Cola. Коллажи с отдельными знаками на однотонном фоне дополнительно проверяются по фрагментам. Упоминания брендов в тексте отмечаются отдельно. Справочный образец помогает опознать знак, а происхождение материала и разрешение на использование требуют отдельных доказательств. Результаты текстового поиска без подтверждённого совпадения не попадают в отчёт о лицензиях.

Формат и условия подключения локального снимка описаны в [справке по реестрам](docs/coursework/legal_snapshots.md).
