# TraceMuse

TraceMuse — локальное веб-приложение для предварительной проверки цифровых материалов перед публикацией. Оно извлекает содержимое и метаданные, сохраняет проверку в SQLite, показывает найденные сведения и формирует PDF и JSON. Поиск в Wikimedia Commons и анализ DeepSeek включаются пользователем для каждой проверки.

## Запуск на Windows 11

Нужны Python 3.13 и Node.js, поддерживаемый установленной версией Vite. Запустите в терминале PowerShell в VS Code, из папки проекта:

```powershell
py -3.13 -m venv backend\.venv
.\backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
.\backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Откройте <http://127.0.0.1:8000>. Для следующих запусков достаточно последней команды. Повторяйте сборку при изменении фронтенда. `Ctrl+C` останавливает сервер. Документация API доступна по адресу <http://127.0.0.1:8000/docs>.

Для разработки запустите backend с `--reload`, а во втором терминале выполните `npm.cmd --prefix frontend run dev` и откройте <http://127.0.0.1:5173>. Vite перенаправляет `/api` на `127.0.0.1:8000`.

## Проверка материала

1. Откройте «Новая проверка» и выберите до 10 файлов общим размером до 100 МиБ. Поддерживаются PDF, DOCX, PPTX, HTML, PNG, JPEG, WEBP, SVG и ZIP.
2. Укажите предполагаемое использование. Для картинок включите «Поиск источников онлайн» и при наличии ключа «Анализ с МАИ» или «Анализ с DeepSeek».
3. После завершения откройте отчёт. Проверьте совпадения и условия на страницах источников. Скачайте PDF или JSON при необходимости.
4. История сохраняется между запусками. Повтор создаёт новую запись. Удаление убирает запись и её локальный исходный файл.

Загруженные файлы, SQLite и локальный ключ хранятся в `backend/data/`. По умолчанию приложение слушает только локальный адрес. Настройки окружения можно задать в `backend/.env` по образцу `backend/.env.example`.

### Готовые исправления для изображений

В отчёте первым идёт раздел «Что сделать с изображениями». Он связывает найденные источники и замены со слайдами PPTX и страницами PDF. Повторяющиеся изображения проверяются вместе. При подтверждённом совпадении и подходящих условиях TraceMuse готовит подпись с автором, ссылкой на источник и ссылкой на лицензию. Для замены он показывает конкретный файл, страницу источника и условия использования. Решение основано на записанных в Commons условиях, а визуальное сходство служит только подсказкой.

ИИ формулирует предметные запросы по контексту и сортирует подходящие замены. Ссылки на документы и условия берутся из каталога. Для одной проверки разбираются до 12 уникальных изображений. В отчёте показано, сколько элементов вошло в этот предел. Без ключа ИИ поиск по хешам, названиям и доступным описаниям также работает.

Для обратного поиска за пределами Commons можно включить Cloud Vision API в своём проекте Google Cloud и задать `GOOGLE_VISION_API_KEY` в локальном `backend/.env`. После перезапуска в новой проверке появится отдельная опция «Обратный поиск изображений». Она отправляет до шести уменьшенных JPEG-копий в Google Cloud Vision. Ссылки на найденные копии показываются как поисковые следы. Условия использования проверяются по отдельному источнику. [Google Cloud Vision Web Detection](https://docs.cloud.google.com/vision/docs/detecting-web)

## DeepSeek

1. Создайте ключ в [кабинете DeepSeek](https://platform.deepseek.com/api_keys).
2. В TraceMuse откройте «Настройки», вставьте ключ и сохраните его. Нажмите «Проверить подключение».
3. Включите анализ DeepSeek при запуске конкретной проверки. Сохранение ключа само по себе не включает передачу данных.

По умолчанию TraceMuse использует `deepseek-flash` (DeepSeek V4.1 Flash). Старые значения `deepseek-v4-flash` и `deepseek-v4-flash-vision-exp` в `DEEPSEEK_MODEL` автоматически приводятся к актуальному идентификатору. [Модели DeepSeek](https://api-docs.deepseek.com/quick_start/pricing)

На Windows клиентский ключ сохраняется через DPAPI текущей учётной записи. На системах POSIX локальный файл ключа доступен только владельцу. Ключ из `backend/.env` можно убрать, удалив соответствующее значение из файла и перезапустив backend.

## API МАИ

Для запуска с университетским шлюзом установите `$env:AI_PROVIDER = 'mai'` перед запуском backend. В «Настройках» появится «МАИ API». Сохраните ключ, выданный МАИ, и нажмите «Проверить подключение». Проверка запрашивает список моделей. Для первого запроса к модели запустите проверку тестового файла с опцией «Анализ с МАИ».

По умолчанию используется `deepseek-v4.1-flash` через `https://api-ai.mai.ru/v1`. Ключи МАИ и публичного DeepSeek сохраняются отдельно. Для выбора другой модели задайте `MAI_MODEL` с точным ID из списка API.

HTTPS-сертификат проверяется по умолчанию. Для разового тестового запуска при ошибке `SEC_E_UNTRUSTED_ROOT` можно явно задать `$env:MAI_TLS_VERIFY = 'false'` перед запуском. Это отключает проверку подлинности только для шлюза МАИ. Ключ и данные при перехвате соединения могут быть раскрыты. Для обычного режима установите `$env:MAI_TLS_VERIFY = 'true'` и используйте доверенную цепочку сертификатов.

## Какие данные передаются

- Без внешних опций обработка выполняется локально. Встроенные ссылки не открываются автоматически.
- При поиске Wikimedia Commons получает ограниченные фрагменты текста, хеши и поисковые запросы из описаний и контекста. TraceMuse может скачать публичные изображения Commons для сравнения.
- При анализе выбранный провайдер получает ограниченные текстовые выдержки, контекст слайдов и выбранные сведения о найденных источниках, кандидатах на замену и реестрах. Оригинальные файлы в модель не передаются.
- При включении отдельной опции обратного поиска Google Cloud Vision получает уменьшенные копии изображений. Они не сохраняются в результатах аудита.

Результаты показывают доступные сведения, происхождение кандидатов и ограничения проверки. Для сканированных PDF OCR не выполняется. Совпадения в Commons и локальном снимке реестра требуют проверки по источнику и контексту применения. Начальный режим проверок РФ показывает официальные ссылки для ручной сверки.

TraceMuse локально сверяет растровую графику со встроенными образцами Pepsi, adidas и Coca-Cola. Коллажи с отдельными знаками на однотонном фоне дополнительно проверяются по фрагментам. Упоминания брендов в тексте отмечаются отдельно. Справочный образец помогает опознать знак, а происхождение материала и разрешение на использование требуют отдельных доказательств. Результаты текстового поиска без подтверждённого совпадения не попадают в отчёт о лицензиях.

Формат и условия подключения локального снимка описаны в [справке по реестрам](docs/coursework/legal_snapshots.md).
